## 裁定待ち

### 👺PL-Q4: `uses` の残り回数はデーモンの再起動をまたぐか

- [ ] a (推奨): またがない。残り回数はデーモンのメモリ上のカウンタで、再起動すると `uses` を持つルールは失効する (通知で数える世代 `os.wake` 等と同じ扱い)。署名付き一覧には `uses: N` の初期値だけが入り、一覧は書き換わらない
- [ ] b: またぐ。残り回数を署名付き一覧に書き戻して再署名する (使うたびに一覧の書き込みが発生する)

a の推奨理由: 一覧が不変のまま。`age` は作成時に `until` へ変換して一覧に入るだけなので、可変状態は `uses` の残り回数だけになる

### 👺PL-Q5: `uses` の残り回数はいつ減らすか

- [ ] a (推奨): アプリが実際に値を渡したときに `policy.record_use(rule_id)` で減らす (現行の文書のとおり)。評価は trace 表示 (「なぜ通るか」) のためにも呼ばれるので、評価で減らすと表示だけで消費する
- [ ] b: 評価が `allow` で通るたびに条件の中で減らす (条件のクロージャがカウンタを持つ)
