## 裁定待ち

HO-Q4 は、別リポ (kawaz/pam-passkey) の作業から出た問いをこのリポに移したもの。推奨は起票側のもの。判断の軸は procline 自身の層と型の設計で、特定のアプリの都合ではない (kawaz 2026-11-15)。

### 👺HO-Q4: アイコンを収集の型から外すか

提案中の [DR-0015](decisions/DR-0015-icon-outside-collection.md)。今は収集の型にアイコンの field があるが未実装。

- [ ] a (起票側の推奨): 収集の型と収集のオプションからアイコンを消し、実行パスから PNG を返す別の関数 (feature `icon`、ImageIO で取り AppKit を読み込まない) にする。アプリは自分のキャッシュに無い時だけ呼ぶ。アセットカタログだけの app のアイコンは取れない
- [ ] b: 収集の中に残す

### 👺PT-Q1: 要求を書いたプロセスと、接続相手として収集されるプロセスの食い違いを、procline が扱うか

[issue](issue/2026-11-15-peer-token-is-last-user-at-read-time.md) の (c)。接続相手の audit token が表すのは「読んだ時点で相手側の端を最後に送受信に使ったプロセスの、その時点の資格情報」で、要求を書いたプロセスとは限らない ([findings](findings/2026-11-15-socketpair-peer-after-fork-exec.md))。同じ uid の別プロセスは、要求を書いた後に許可されたバイナリを自分で exec すれば、収集の結果をそのバイナリのものにできる。macOS の UNIX ドメインソケットには、メッセージごとに書き手の資格情報を付ける手段が無い。

- [ ] a (統括の推奨): procline は扱わず、境界に書く。`collect_peer` が保証するのは「収集の時点で相手側の端を最後に使ったプロセスを、収集の間に変わらなかった個体として集める」までと DESIGN に定義し、「要求を書いたのがそのプロセスであること」はアプリのプロトコルの責務と書く (例: 収集の後に相手に応答させ、応答の後で相手が同じ個体のままかを確かめる。許可されたバイナリは応答しないので、exec ですり替えた相手は応答できない。この手順が十分かは未観測)。入口も型も増えない。ACL を UNIX ドメインソケットの相手に当てるアプリは、全部がこの手順を自分で持つことになる
- [ ] b: procline が扱う。収集した相手が今も同じ個体かを確かめ直す入口など、アプリのプロトコルが使う部品を procline が持ち、DESIGN に手順を書く。アプリごとの実装のぶれは減るが、収集の入口が増え、通信のプロトコル (procline が今まで持たなかった層) に踏み込む

## 確認待ち

### 👺HO-C1: DR-0011 (署名の型と信頼の印) と DR-0012 (クラスを保護の状態で決める) は kawaz の裁定か

どちらも 2026-11-15 に pam-passkey の前任セッションが設計・実装して `Active` / 実装済にしたもの。引き継いだセッションは、kawaz の裁定だったかを持っていない。[DR-0012](decisions/DR-0012-strength-class-from-protection.md) は、このリポで 2026-11-09 に統括が置いた扱い (hardened runtime の有無はクラスの判定に使わず、脅威モデルの前提に書くだけ) を、観測 (保護の無い署名済みバイナリは、同じ uid が `DYLD_INSERT_LIBRARIES` を付けて起動するだけで署名由来の条件を満たす) を根拠に改めている。

実機での帰結 (2026-11-15、この Mac): Claude Code は公証済みで hardened runtime だが entitlement `com.apple.security.cs.disable-library-validation` を持つので「開いている」になり、`binary` の署名由来の field も `process` も弱になる。zsh (Apple) は保護ありで強、ad-hoc の自作バイナリは弱。

- [ ] a: 両方このまま (kawaz の裁定済み、または今この内容で採る)
- [ ] b: DR-0012 は採るが、扱いを変えたい点がある (内容を教えてください)
- [ ] c: DR-0012 を提案に戻し、クラスは保護の状態で変えない
